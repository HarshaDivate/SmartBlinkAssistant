# Smart Blink Assistant 

**Smart Blink Assistant** is a personal project that monitors your blinking habits to reduce eye strain while using digital devices. Built with HTML, CSS, JavaScript, and MediaPipe for real-time webcam blink detection.

---

## Features

- Real-time blink detection using your webcam.
- Blink counter with daily logging and streak tracking.
- Interactive charts showing blink history (using Chart.js).
- Daily goals with badges to motivate healthy habits.
- CSV export of blink data for personal tracking.

---

## Technologies Used

- **HTML5 & CSS3** – Structure and styling
- **JavaScript (ES6)** – Functionality & timers
- **MediaPipe FaceMesh** – Eye landmarks & blink detection
- **Chart.js** – Visualizing blink data
- **LocalStorage** – Saving daily blink counts and streaks

---

## Usage

1. Clone or download this repository.
2. Open `index.html` with a browser (or use VS Code Live Server).
3. Allow webcam access when prompted.
4. Follow the on-screen blink reminders and track your progress.
